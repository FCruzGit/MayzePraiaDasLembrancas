# MayzePraiaDasLembrancas
Este game é um RPG de ação 2D top-down, onde você controla a cachorrinha Mayze, que acordou perdida numa praia e precisa achar sua família. Tem combate, inimigos, inventário, XP/níveis e árvore de habilidades.

````markdown
main.py       → o game loop + interface (HUD, diálogos, tela de habilidades)
mayze.py      → o Player (a Mayze) e o carregamento dos sprites dela
inimigo.py    → os inimigos (caranguejos) com IA de patrulha e perseguição
mapa.py       → o mundo, a câmera e os objetos do cenário
inventario.py → sistema de itens e mochila
assets/mayze/ → as imagens (sprites) da personagem
````
